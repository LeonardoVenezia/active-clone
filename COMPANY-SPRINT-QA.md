## Gated variable preview preparation (not yet enabled)

Public GET/POST require both COMPANY_VARIABLES_PREVIEW_ENABLED and COMPANY_VARIABLES_POLICY_APPROVED, plus existing console context, exact owner/admin preview policy and encrypted storage enabled. Role policy is proposed only, pending user approval. Definitions come from server configuration COMPANY_VARIABLE_DEFINITIONS, keyed by exact organization ID. Client cannot choose tenant, add keys or change secret classification. No value is returned by the endpoint, including nonsecret values. This is a preparation contract, not a full agency definitions UI.

It cannot guarantee against arbitrary provider console logs or arbitrary new encodings. No runtime flags may be enabled until the actual adapter path is audited and tested. The temporary local-only API harness is outside this repository. Production execution and variable policies remain closed.
